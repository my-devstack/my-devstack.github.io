How It Works

MyDevStack ships as a single Docker image that bundles the Vue frontend and a Go REST API proxy, connecting to any AWS-compatible local emulator. It does not include an emulator.

1

Bring Your Emulator

MyDevStack does not bundle one. It connects to LocalStack, FloCi, MiniStack, or any AWS-compatible local endpoint you already run.

2

Run the Docker Image

One command starts the frontend and the Go proxy. The proxy handles all AWS SDK communication.

3

Open the Control Panel

Create, edit, and delete resources on any of the 25+ services — all without touching the terminal.

Quick Start

Get MyDevStack running in seconds with a single command. Just point it at your local AWS emulator and you are ready to go.

docker-compose.yml 
services:
  mydevstack:
    image: beabys/mydevstack:latest
    container_name: mydevstack
    ports:
      # UI
      - "3000:3000"
      # Proxy port for AWS emulator connection
      - "8081:8081"
    environment:
      AWS_ENDPOINT: http://host.docker.internal:4566
      AWS_ACCESS_KEY_ID: test
      AWS_SECRET_ACCESS_KEY: test
      PROXY_PORT: 8081
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:3000/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 10s
    networks:
      - mydevstack-network

  networks:
    mydevstack-network:
      name: mydevstack-network
      driver: bridge
Alternatively, run directly with the Docker CLI:
Terminal 
docker run -d \
  --name mydevstack \
  -p 3000:3000 \
  -p 8081:8081 \
  -e AWS_ENDPOINT=http://host.docker.internal:4566 \
  -e AWS_ACCESS_KEY_ID=test \
  -e AWS_SECRET_ACCESS_KEY=test \
  -e PROXY_PORT=8081 \
  --restart unless-stopped \
  beabys/mydevstack:latest

Prerequisite: AWS Emulator

Before starting MyDevStack, make sure you have an AWS emulator running locally — such as LocalStack, MiniStack, or FloCi on port 4566. MyDevStack connects to it through the configured AWS_ENDPOINT. MyDevStack does not include an emulator — you start it separately.

Frequently Asked Questions

Is MyDevStack a read-only monitoring dashboard? ▾

No. MyDevStack is a full CRUD control panel. You create, edit, and delete resources across all 25+ supported AWS services directly from the UI. Most service pages also include built-in usage examples for AWS CLI, JavaScript, Python, and Go.

Do I need an AWS account or real AWS credentials? ▾

No. MyDevStack talks to a local AWS emulator such as LocalStack, FloCi, or MiniStack. Any values you enter for AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY are forwarded to the emulator; no real AWS account, IAM user, or billing relationship is required.

Does MyDevStack work offline? ▾

Yes. Once the Docker container and your chosen local emulator are running, everything works without internet access. The UI, the Go proxy, and the emulator all stay on your machine.

Does MyDevStack include an emulator? ▾

No. MyDevStack is only the UI — a Vue frontend plus a Go proxy in one Docker image. It ships no emulator and no AWS services. It connects to any AWS-compatible endpoint you already run; LocalStack, FloCi, and MiniStack are simply the endpoints it is most often pointed at.

Is MyDevStack free and open source? ▾

Yes. MyDevStack is released under the MIT license. The Docker image is free, the source is public on GitHub, and there are no paid tiers, no telemetry, and no usage limits.
